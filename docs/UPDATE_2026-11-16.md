## 확인한 문제와 수정

개발 미리보기를 켠 상태에서 프로덕션 빌드를 실행하면, 검색용 HTML 생성에 사용하는 Vite 서버가 개발 서버와 같은 `node_modules/.vite` 캐시를 덮어썼다. 개발 페이지가 참조하던 Phaser 사전 번들이 사라져 동적 모듈을 가져오지 못하고 게임 로딩 실패 안내가 나타나는 것을 재현했다.

- HTML 생성용 캐시를 `node_modules/.vite-prerender`로 분리했다.
- 초기화 예외의 원인을 콘솔에 기록하도록 보완했다. 사용자에게는 기존 로딩 오류 안내를 유지한다.
- 수정 후 미리보기를 실행하면서 `npm run check`를 수행해, 개발 캐시 메타데이터가 바뀌지 않고 Phaser 번들도 유지되는 것을 확인했다.
- 브라우저에서 게임 시작, 새 게임, 키보드 입력, 일시정지·재개, 조작법 열기·닫기, 게임 포기를 확인했다. 320px·390px 폭에서 가로 넘침이 없음을 확인했다.
