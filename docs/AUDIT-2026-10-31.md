## 검증

- Node 내장 테스트 **50개 통과**: 1~4줄 및 떨어진 행 제거, 점수·콤보, 홀드·충돌, 회전·벽·바닥 보정, 일시정지·재시작, 입력 취소·반복 타이머, 손상·차단된 저장소.
- 고정 시드로 **12,000번의 게임 동작**을 실행하며 보드 크기·현재 블록 충돌·줄 제거 중 상태 불변 조건 확인.
- Vite 프로덕션 빌드 통과. `prebuild`에서 테스트를 실행하므로 회귀 테스트 실패 시 Vercel 빌드도 중단된다.
- `npm audit`: 점검 전 **9건** → 업데이트 후 **0건**. Vite 7.3.7, React 18.3.1, Phaser 3.90.0. 잠금 파일로 동일한 설치 결과 유지.
- 브라우저 미리보기: 데스크톱 1280×840, 휴대폰 폭 320·393, 태블릿 768, 가로 568×320. 화면 밖으로 잘리는 조작 버튼 없음, 조작 버튼 최소 44px.
- 브라우저에서 이동·회전·하드 드롭·홀드, 정지/재개, 조작법 열기·Escape 닫기, 게임 종료, 음소거 유지, 저장된 1,200점 복원, 손상된 점수의 0점 복구 확인.
- 미리보기 전용 재현 도구로 **4줄 → 1,200점·콤보 1**, 막힌 홀드의 종료, 줄 제거 중 재시작 후 **0줄·0점**, 5회 반복 재시작 후 게임 캔버스 1개와 단일 P 키 정지 확인.
- 검증용 페이지·게임 참조는 운영 빌드에서 제외한다.

모바일 검증은 브라우저의 화면 크기별 레이아웃과 버튼 조작, 입력 로직 자동 테스트 기준이다. 실제 iPhone Safari·Android 기기에서 직접 실행한 결과는 아니다. Phaser 전용 청크의 500kB 경고는 남아 있으며, 게임 엔진을 별도 청크로 캐시한다. 자동 취약점 검사는 검사 시점의 공개 데이터 기준이다.
