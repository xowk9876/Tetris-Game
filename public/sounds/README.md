# 테트리스 사운드

게임판과 조작은 오디오 다운로드를 기다리지 않고 시작합니다. 음소거 상태에서는 소리 파일을 요청하지 않습니다. 브라우저가 배경음악 자동 재생을 차단하면 다음 게임 조작에서 재생을 다시 시도합니다.

| 파일 | 재생 시점 |
| --- | --- |
| `bgm.mp3` | 게임 진행 중 반복 재생 |
| `drop.wav` | 블록 고정 |
| `tetris.wav` | 한 줄 이상 제거 |
| `game_over.wav` | 게임 종료 |

파일 이름이나 형식을 바꾸면 `src/utils/gameAudio.js`의 파일 목록도 함께 수정합니다.
